# 📝 Simple Registration Form

A simple and responsive **Registration Form** built using **HTML, JavaScript, and Tailwind CSS**.  
This project demonstrates form design, user input handling, client-side validation, and responsive UI development.

## 🚀 Features

- 📝 User Registration Form
- 👤 Name Input
- 📧 Email Input
- 🔐 Password Input
- ✅ Form Validation
- ⚠️ Error Messages
- 📱 Responsive Design
- 🎨 Modern UI using Tailwind CSS
- ⚡ JavaScript-based Validation

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 Tailwind CSS
- ⚡ JavaScript
- 📦 NPM
- 🧩 Tailwind CSS CLI
